Cài đặt kết nối Google Sheet

Để tiện ích tự động ghi dữ liệu vào bảng tính của bạn mà không cần server, hãy dán đường link Apps Script Web App URL bên dưới.

Mở Google Sheet -> Extensions -> Apps Script -> Deploy as Web App (Anyone).
📖 Xem hướng dẫn lấy Web App URL trong 30 giây
  1. Mở file Google Sheet có sẵn của bạn.
  2. Chọn Tiện ích mở rộng (Extensions) > Apps Script.
  3. Dán mã nguồn từ file google_apps_script.js vào.
  4. Bấm Triển khai (Deploy) > Tùy chọn triển khai mới (New deployment).
  5. Loại chọn: Ứng dụng web (Web app), Ai có quyền truy cập chọn: Bất kỳ ai (Anyone).
  6. Bấm Triển khai và sao chép đường link dán vào ô bên trên!
